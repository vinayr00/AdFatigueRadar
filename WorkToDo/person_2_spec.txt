6. Required Risk Engine
6.1 Audience Risk
audience_risk =  0.30 × harmful_negative_ratio_signal+ 0.25 × sentiment_decay_signal+ 0.20 × fatigue_mockery_signal+ 0.10 × comment_acceleration_signal+ 0.10 × ctr_frequency_signal+ 0.05 × critical_complaint_signal
6.2 Economic Risk
economic_risk =  0.55 × cpa_cpm_signal+ 0.45 × roas_conversion_signal
6.3 Normalization
signal = clip((x - low) / (high - low), 0, 1)
Use thresholds.yaml as the single source of normalization bounds.
Never silently substitute alternate bounds inside Python.
7. Exact Feature Definitions
7.1 Harmful Negative Ratio
Weighted harmful share:
product_complaint = 1.00service_complaint  = 1.00fatigue            = 0.80mockery            = 0.75spam               = 0.60banter_meme        = 0.00neutral            = 0.00positive           = 0.00
Apply Wilson lower bound to the fractional harmful count.
Do not use raw Stage-1 negative sentiment for the production harmful ratio.
7.2 Sentiment Decay
Use category-aware weighted sentiment so banter_meme cannot inflate the decay signal.
Compute decay over the configured rolling/guard window.
Use EWMA alpha from thresholds.yaml.
7.3 Fatigue / Mockery
Use the configured category mix.
Do not infer fatigue solely from a keyword such as 'again'; rely on Person 1's category output.
7.4 Comment Acceleration
Measure change in comment rate over time using the configured five-minute step.
Do not count a single author's burst as independent evidence; anomaly controls apply.
7.5 CTR / Frequency
ctr_frequency_signal = mean(norm(ctr_decay_pct), norm(frequency_increase_pct))
7.6 Critical Complaint
Consume Person 1's critical_complaint flag and aggregate its rate.
The production Path B gate also requires confidence/evidence/persistence/anomaly conditions.
7.7 Economic Signals
cpa_cpm_signal = max(norm(cpa_delta_pct), norm(cpm_delta_pct))roas_conversion_signal = max(norm(roas_drop_pct), norm(conv_rate_drop_pct))
8. Wilson Lower Bound
Implement the Wilson lower bound for fractional harmful counts. Required confidence z = 1.96.
p = k_eff / ncenter = (p + z*z/(2*n)) / (1 + z*z/n)margin = z * sqrt((p*(1-p) + z*z/(4*n)) / n) / (1 + z*z/n)wilson_lb = center - margin
Guard n <= 0.
Keep k_eff within [0,n].
Run calibration checks at n = 24, 30, 60, 120, 480.
9. Anomaly Controls
top_author_share > 0.30 → anomaly true.
duplicate_cluster_share > 0.40 → anomaly true.
per-author maximum comments per rolling window = 3 before aggregation.
Path B emergency pause is blocked whenever anomaly is true.
Do not remove suspicious comments from the dataset; flag them and preserve auditability.
10. Severity and Campaign State
Keep severity and campaign state as separate concepts.
Severity:HEALTHY / WATCH / WARNING / CRITICALCampaign state:ACTIVE / SOFT_REDUCED / PAUSED / BLOCKED
Do not encode severity directly as state.
State transitions must be deterministic and auditable.
11. Gate Logic
11.1 WATCH
audience_risk >= 0.50.
11.2 WARNING
audience_risk >= 0.65 for 0.5 simulated hours.
WARNING is alert-only; it must not change campaign state.
11.3 SOFT_REDUCED
audience_risk >= 0.75 for 1.0 simulated hour.
Apply soft_budget_multiplier = 0.80 through the shared ActionSimulation interface.
11.4 PAUSE Path A
audience_risk >= 0.85.
economic_risk >= 0.70.
At least 20 conversions in rolling hour.
Evidence thresholds pass.
Classifier confidence threshold passes.
Wilson lower-bound threshold passes.
Persistence requirement passes.
Cooldown is clear.
Readback must be verified after action.
11.5 PAUSE Path B — Emergency Critical Complaint
Critical complaint rate >= 0.20.
Critical complaint confidence >= 0.85.
At least 10 distinct authors.
Anomaly must be false.
Persistence = 0.25 simulated hours.
Cooldown clear.
This path can operate without economic confirmation because the trigger itself is the critical-complaint emergency condition.
11.6 Recovery / Hysteresis
Soft recovery threshold = 0.60.
Warning recovery threshold = 0.45.
Recovery persistence = 1.0 hour.
Unpause is explicit/operator-controlled unless the final state rules explicitly permit recovery.
Manual BLOCKED state must not auto-recover.
12. Staleness
stale_after_steps = 2.
Check ACTIVE and SOFT_REDUCED.
Paused campaigns emit zero-volume heartbeat telemetry every five minutes.
Do not mark PAUSED campaigns stale merely because CPA is null.
Fresh telemetry clears stale condition automatically where permitted.
13. Economic Action Simulation
Person 2 owns the shared runtime action/simulation interface; Person 3 owns generation of potential-world curves.
class ActionSimulation:    def apply(self, potential_event, campaign_state):        ...
ACTIVE → full potential volume.
SOFT_REDUCED → volume × 0.80.
PAUSED → zero new spend/volume, but heartbeat telemetry continues.
CPA is null when conversions are zero; never emit infinity.
Protected and no-action simulations must consume identical potential-world curves and identical seeds.
14. Economic Evaluation
excess_cost = spend * max(0, 1 - baseline_CPA/current_CPA)excess_cost_avoided = no_action_excess_cost - protected_excess_costconversions_forgone = max(0, no_action_conversions - protected_conversions)tradeoff = excess_cost_avoided / max(1, conversions_forgone)
Never call raw spend reduction 'savings'.
Report excess cost avoided per conversion forgone.
Report action timing and false-positive behavior.
15. Sandbox Action Execution
P0 action mode is SANDBOX only.
PAUSE must be idempotent.
After action, perform readback verification.
Readback failure fails closed.
Record previous state and new state.
Record reason codes, risk values, config version, confidence, and audit ID.

API key must be server-side and loaded from environment configuration.

Provider/Slack secrets must remain in environment variables.
